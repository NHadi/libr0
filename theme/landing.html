Learn by Building

Each chapter builds on the previous one, showing you exactly how Rust's fundamental types work under the hood. No magic, no hand-waving.

ch.01

Option<T>

The simplest enum. Pattern matching, Some(T) and None. Combinators and unwrapping.

ch.02

Result<T, E>

Error handling with Ok(T) and Err(E). The ? operator and error propagation.

ch.03

Box<T>

First heap allocation. Stack vs heap, Deref trait, and pointer indirection.

ch.04

Vec<T>

Growable arrays. Capacity, reallocation, and why String is just Vec<u8>.

ch.05

Cell<T>

Interior mutability. UnsafeCell under the hood, move semantics for mutation.

ch.06

RefCell<T>

Runtime borrow checking. Guard types, panic on violation, dynamic borrowing.

ch.07

Rc<T>

Reference counting for shared ownership. Strong and weak references.

ch.08

Rc<RefCell<T>>

Shared mutable state. Build graphs, trees, and cyclic structures.
