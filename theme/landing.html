Learn by Building

libr0 takes you through Rust's fundamental types from scratch. Each chapter builds on the previous one.

Box

First heap allocation. Stack vs heap, Deref trait.

Option

The simplest enum. Pattern matching with Some & None.

Result

Error handling with Ok(T) & Err(E). The ? operator.

Vec

Growable arrays. Why String is just Vec<u8>.

RefCell

Runtime borrow checking with guard types. Understand interior mutability deeply.

Cell

Interior mutability with UnsafeCell under the hood.

Rc

Reference counting for shared ownership.

Rc+RefCell

Shared mutable state. Build graphs and trees.

What Makes libr0 Different?

De-abstract the Abstractions

Box? Just alloc + dealloc in a struct. RefCell? Just a counter and panic! We show you exactly how it works without the magic.

Show the Memory

What's in memory? Show the layout. What does the CPU do? Explain the instruction. Working code beats theory every single time.
